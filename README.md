# FaktorialExperiments

Static Pacman experiments built with plain HTML, CSS, and JavaScript.

## Run Locally

Open `index.html` directly in a browser, or serve the repository root with a
small local web server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

Use the arrow keys or WASD to move, press `R` or the restart button to reset the
game, and avoid the ghosts while clearing all pellets.
